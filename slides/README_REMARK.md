# 🚀 Presentaciones con Remark.js (Versión Simple)

## ¿Qué es esto?

Esta es una **versión simplificada** de las presentaciones que **NO requiere instalación** de Node.js ni Slidev. Perfecta para profesores que quieren abrir las slides rápidamente.

## 🎯 Cómo Abrir las Presentaciones

### ✅ Método 1: Doble Clic (Más Fácil)

1. Navega a la carpeta `slides/`
2. Busca el archivo `.html` (ejemplo: `semana1-medidas-descriptivas-remark.html`)
3. **Doble clic** en el archivo
4. Se abrirá automáticamente en tu navegador predeterminado

**¡Listo! No necesitas instalar nada.**

---

### ✅ Método 2: Arrastrar al Navegador

1. Abre tu navegador favorito (Chrome, Firefox, Edge, Safari)
2. Arrastra el archivo `.html` a la ventana del navegador
3. La presentación se abrirá automáticamente

## 🔧 Personalización (Opcional)

Si sabes HTML/CSS, puedes editar el archivo `.html` directamente:

1. Abre el archivo con un editor de texto (VS Code, Notepad++, Sublime)
2. Busca la sección `<style>` para cambiar colores/fuentes
3. Busca `<textarea id="source">` para editar el contenido de las slides
4. Guarda y recarga en el navegador

**Estructura del contenido:**
```markdown
# Título de Slide

Contenido aquí...

---

# Siguiente Slide

Más contenido...
```

Las slides se separan con `---`

## ❓ Preguntas Frecuentes

**P: ¿Funciona sin internet?**
R: Sí, después de la primera carga. Remark se carga desde CDN pero queda en caché del navegador.

**P: ¿Puedo compartir el archivo por email?**
R: Sí, es un solo archivo HTML autocontenido.

**P: ¿Puedo imprimir las slides?**
R: Sí, presiona Ctrl+P (Cmd+P en Mac) y selecciona "Guardar como PDF".

**P: ¿Por qué no se ven los diagramas Mermaid?**
R: Asegúrate de tener conexión a internet la primera vez que abres el archivo (Mermaid se carga desde CDN).

**P: ¿Puedo usar esto en un iPad/Tablet?**
R: Sí, funciona en cualquier navegador moderno.
